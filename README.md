# Portfólio - Desafio 01

Um portfolio pessoal em HTML, CSS e JavaScript com visual inspirado em céu noturno, estrelas, lua e efeitos de meteoros.

## ✨ Visão geral

Este projeto foi desenvolvido como parte do desafio de criação de um portfólio pessoal, com:

- página inicial com apresentação e botões de navegação
- menu responsivo com botão hamburger
- seção de projetos em cards
- seção de certificados e sobre mim
- visual customizado com tema espacial

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome

## ▶️ Como executar

### Opção 1

Basta abrir o arquivo `index.html` no navegador.

### Opção 2

Se quiser rodar em um servidor local:

```bash
python -m http.server 8000
```

Depois acesse:

```text
http://localhost:8000
```

## 🎨 Personalização

Você pode alterar:

- texto da apresentação no `index.html`
- cores e layout em `style.css`
- fundo e efeitos do céu em `background.css`
- menu em `css/menu.css`
- cards de projetos em `css/project.css`

## 📌 Observação

O projeto está estruturado como um exemplo didático e pode ser facilmente expandido com mais páginas, fotos, projetos e links sociais.
